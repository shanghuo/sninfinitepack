# 得一即无限背包（SN Infinite Pack）模组

- 版本：`sninfinitepack-1.0.2-mc1.7.10.jar`（1.7.10）/ `sninfinitepack-1.0.2-mc1.12.2.jar`（1.12.2）
- 适用：Minecraft **1.7.10**（Forge 10.13.4.1614）+ **1.12.2**（Forge 14.23.5.2864），原版/基础模组/整合包（如 GTNH）均可
- **0 依赖**：只依赖 MC 原版 + Forge/FML 核心 API，不依赖任何第三方模组 / GTNH 特有内容。
- **不冲突**：与其它模组不冲突、不覆盖任何内容；数据随服务器存档保存，重开不丢。

## 功能

**计数制「得一即无限」**：放入任意物品，同变体自动累加计数；取出会减少计数，**计数可为负（负数 = 无限透支，仍能取出）**，让玩家感知自己用了多少、想补回正数。
- **变体精确匹配**：物品注册名 + 耐久 + 完整 NBT 深度等价 = 同一条目（满耐久弓 vs 消耗过弓、不同附魔/模组属性/自定义 NBT = 各自独立条目）。
- **排序 + 搜索**：状态行搜索框按物品名（本地化，中文可用）过滤；点击「排序:XX」循环切换 默认 / 最近存取 / 数量升 / 数量降。
- 每条目右下角显示计数：**正数白色、负数/0 红色**；**大数自动缩写（K/M/G，如 1.2K / 3.4M / 1.5G），悬停显示精确数量**。
- 删除即不再可取（删除模式两次点击确认）。
- **持久化**：数据保存在服务器存档中，重开不丢。

## 使用（箱子式操作）

1. 打开背包 GUI：手持「得一即无限背包」右键。
2. **存入**：拿起物品直接点进任意条目格即存入（整个 9×6 区域都是条目格，插到该格）；或 Shift+点击玩家背包物品整组存入。
3. **取出**：左键条目 = 整组、右键 = 1 个、Shift+左键 = 整组。取出后计数减少（可为负）。
4. **删除**：点右上角按钮切到「删除模式」（红色覆盖），空手左键条目**第一次点击黄色高亮标记、第二次同格确认删除**；点别处/滚轮/切模式取消。
5. **搜索/排序**：状态行搜索框输入物品名过滤；点击「排序:XX」循环切换排序方式。
6. 滚动：鼠标滚轮**一行一行翻**（每次 9 条）；一次滚动动作只翻一行（连滚自动合并）。

## 获取物品

- **合成**：工作台 3×3 —— 周围 8 个泥土（任意）+ 中间 1 个木头/原木（任意）。
- 创造模式：搜索「得一即无限背包」标签页。
- 命令（需要权限/作弊）：`/give <玩家名> sninfinitepack:infinitePack 1`（**1.7.10**）；`/give <玩家名> sninfinitepack:infinitepack 1`（**1.12.2**，注册名全小写）。

## 安装

- **1.7.10 客户端**：把 `sninfinitepack-1.0.2-mc1.7.10.jar` 放入 `.minecraft/mods/`。
- **1.12.2 客户端**：把 `sninfinitepack-1.0.2-mc1.12.2.jar` 放入 `.minecraft/mods/`。
- **服务器**：与客户端**同版本**的 jar 放入服务器 `mods/` 目录（存储逻辑在服务端运行，**服务端必须也装**）。
- **放入前先关闭游戏/服务器**，放入后重启；升级时先移除旧的 `sninfinitepack-*.jar`（同 modid 冲突会双加载）。

## 强制生存指令（lock，可选功能）

- 指令 `/snanginflock`：`/snanginflock <密码> <on|off>`（启停支持 on/off、1/0、true/false）；无参数显示帮助 + 当前状态。
- 开启后对所有存档生效：**创造模式创建的存档** → 禁止游玩（客户端全屏「当前存档禁止游玩」，只能返回标题）；**生存模式创建的存档** → 玩家切创造会自动改回生存。
- 开启自动开启**死亡不掉落**（keepInventory），关闭时按维度还原开启前状态；关闭需密码正确，关闭后密码失效。
