# 得一即无限背包（SN Infinite Pack）模组

- 版本：`sninfinitepack-1.0.0.jar`
- 适用：Minecraft 1.7.10 / Forge 10.13.4.1614（GTNH 2.8.4 已用环境）
- 仅依赖核心 Forge API，与所有现有模组兼容（不冲突、不覆盖任何模组内容）

## 功能

**计数制「得一即无限」**：放入任意物品，同变体自动累加计数；取出会减少计数，**计数可为负（负数 = 无限透支，仍能取出）**，让玩家感知自己用了多少、想补回正数。
- **变体精确匹配**：物品注册名 + 耐久 + 完整 NBT 深度等价 = 同一条目（满耐久弓 vs 消耗过弓、不同附魔/模组属性/自定义 NBT = 各自独立条目）。
- 每条目右下角显示计数：**正数白色、负数/0 红色**；**大数自动缩写（万/亿），悬停显示精确数量**。
- 删除即不再可取（删除模式两次点击确认）。
- 数据保存在背包物品自身 NBT 里，可随物品携带/存放，不依赖世界文件/数据库。

## 使用（箱子式操作）

1. 打开背包 GUI：手持「得一即无限背包」右键。
2. **存入**：拿起物品直接点进任意条目格即存入（整个 9×6 区域都是条目格，插到该格）；或 Shift+点击玩家背包物品整组存入。
3. **取出**：左键条目 = 整组、右键 = 1 个、Shift+左键 = 整组。取出后计数减少（可为负）。
4. **删除**：点右上角按钮切到「删除模式」（红色覆盖），空手左键条目**第一次点击黄色高亮标记、第二次同格确认删除**；点别处/滚轮/切模式取消。
5. 滚动：鼠标滚轮翻页（每 54 条一页）。

## 获取物品

- **合成**：工作台 3×3 —— 周围 8 个泥土（任意）+ 中间 1 个木头/原木（任意）。
- 创造模式：搜索「SN 得一即无限背包」标签页。
- 命令：`/give <玩家名> sninfinitepack:infinitePack 1`（需要权限/作弊）。

## 安装

- **客户端**：把 `sninfinitepack-1.0.0.jar` 放入 `.minecraft/mods/`。
- **服务器**：同样的 jar 放入服务器 `mods/` 目录（存储逻辑在服务端运行，**服务端必须也装**）。
- **放入前先关闭游戏/服务器**，放入后重启。

- 产物：`docker/dist/sninfinitepack-1.0.0.jar`
- 源码：`docker/mcmod/src/main/java/com/infpack/`
